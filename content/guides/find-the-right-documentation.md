# Find the right project documentation

## Outcome

You will find the canonical procedure or the owner who can provide it.

## Choose your path

| What you know | Start with |
|---|---|
| The desired outcome | Search **How-tos** and **Guided paths** |
| The project name | Browse **Projects** |
| A short question | Search **FAQs** |
| An exact shared value or rule | Browse **Reference** |
| None of these | Search using the words you would ask a teammate |

## Follow the ownership trail

1. Open the closest matching hub page.
2. Check its project tags and owner.
3. Follow its canonical project links for implementation-specific detail.
4. If the information is missing, contact the named owner and include the page
   URL and the outcome you were trying to achieve.

## Completion checklist

- [ ] The source names an accountable owner.
- [ ] The instructions apply to the current project and environment.
- [ ] The source is within its review period.
