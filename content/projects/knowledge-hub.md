# Project Knowledge Hub

## Purpose

The hub makes cross-project work discoverable without moving each project's
technical source of truth. It publishes project overviews, focused procedures,
guided journeys, shared reference, and concise answers.

## Use this project when

- a task starts in one project and finishes in another;
- the same question is repeatedly asked across teams;
- readers need to discover the right project or owner; or
- a shared policy needs one maintained explanation.

## Do not use it when

- documentation is generated from a project's code;
- a runbook applies to only one implementation; or
- content duplicates a canonical project page.

Link to project-owned material instead.

## Ownership and support

The `knowledge-hub-maintainers` group owns structure and publishing. Each page's
front matter names the team accountable for its factual content.
