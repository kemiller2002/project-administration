# Where should documentation live?

Project-specific facts stay in the repository or documentation space owned by
that project. Cross-project journeys, shared procedures, and discovery pages
live in this hub and link back to those canonical facts.

If one project is clearly accountable for the definition, keep the definition
there. The hub can provide a short explanation that helps readers find and use
it, but should not maintain a second copy.
